Choisir un test d’hypothèse

Réponds aux questions dans l’ordre. Le site propose un test à envisager et les précautions associées.

Arbre de décision — vue synthétique

Mesures continues

Comparer les moyennes → test t, Welch ou ANOVA si les hypothèses conviennent ; sinon envisager des méthodes robustes ou non paramétriques.

Comparer les dispersions → F, Bartlett, Levene / Brown–Forsythe.

Attributs

Une proportion → test binomial.

Deux proportions indépendantes → test de deux proportions.

Plusieurs proportions → test du χ² ; observations appariées → méthodes adaptées.

La normalité n’est pas le seul critère. Indépendance, appariement, effectifs et égalité éventuelle des variances sont déterminants.
