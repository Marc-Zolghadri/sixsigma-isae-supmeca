Procédure 07 · Capabilité

Identifier une loi continue adaptée

Source : diapositives 27–30 du PowerPoint fourni

Procédure pas à pas

  1. Ouvrir Analyse → Distribution.
  2. Placer la colonne d’intérêt dans Y, Colonnes puis valider.
  3. Dans le rapport de la variable, cliquer sur le triangle rouge.
  4. Ouvrir Ajustement continu → Tout ajuster, si cette option est disponible.
  5. Comparer les ajustements proposés (notamment AICc et graphiques de diagnostic).
  6. Pour examiner une loi particulière, ouvrir son ajustement puis Graphiques de diagnostic → QQ Plot.

Jeu de données / résultat

Fichier cité : Capability-Queue Times.xls

Point de vigilance : Une faible valeur AICc sélectionne un meilleur modèle relatif parmi ceux comparés ; elle ne démontre pas à elle seule que la loi est vraie.
