Procédure 32 · Tests d’hypothèses

Comparer plusieurs variances

Source : diapositives 113–115 du PowerPoint fourni

Procédure pas à pas

  1. Vérifier que la variable de groupe (Desk) est catégorielle.
  2. Ouvrir Analyse → Ajuster Y en fonction de X.
  3. Placer la durée en Y et le service en X.
  4. Dans le triangle rouge, choisir Variances inégales.
  5. Examiner les tests proposés (Levene, Bartlett, O’Brien, Brown–Forsythe) et sélectionner selon les hypothèses.

Jeu de données / résultat

Fichier cité : Test for Equal Variances.xls

Point de vigilance : Le test global significatif indique qu’au moins une variance diffère, pas que toutes sont différentes.
