Procédure 03 · Graphiques

Créer un graphique avec le Constructeur de graphiques

Source : diapositives 5 du PowerPoint fourni

Procédure pas à pas

  1. Sélectionner Graphique → Constructeur de graphiques.
  2. Choisir le type de graphique souhaité.
  3. Glisser la variable explicative vers X et la variable étudiée vers Y, selon l’objectif.
  4. Ajuster les éléments de représentation puis terminer.

Jeu de données / résultat

Un graphique correctement paramétré.
